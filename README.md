# Python CLI Template

A basic [copier](https://copier.readthedocs.io/en/stable/) template for spinning up a python cli with [typer](https://typer.tiangolo.com/)

## How to use

- Install copier as per the copier docs
- Copy the template with
  ```bash
  copier copy <path-to-python-cli-template> <target-path>
  ```
  and follow the interactive prompts
- cd into new directory and run `uv sync`
