# Python Library Template

A basic template for spinning up a python library with [uv](https://docs.astral.sh/uv/)

## How to use

- Install [uv](https://docs.astral.sh/uv/)
- from the root directory run `uv sync`

## Installation

To install the library as a dependency in another project run

```bash
uv add <package-name>
```

Or to install from a local path:

```bash
uv add path/to/this/library
```
